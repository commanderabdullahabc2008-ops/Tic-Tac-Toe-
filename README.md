# 🎮 Console-Based Tic-Tac-Toe Game in Python

## 📌 Project Description

This project is a Python-based **Console Tic-Tac-Toe Game** that simulates the classic 3×3 grid game. The application allows users to play against another player or challenge a computer opponent through an interactive command-line interface.

The program uses a 2D list to represent the game board and implements fundamental programming concepts such as functions, loops, conditional statements, input validation, random number generation, and game-state management.

The main purpose of this project is to strengthen Python programming fundamentals and develop problem-solving skills by designing a complete interactive game from scratch.

---

# ✨ Features

## 🎮 Game Modes

- **Player vs Player**
  - Two users can play against each other on the same system.

- **Player vs Computer**
  - A user can play against a computer opponent that generates valid random moves.

---

## 🧩 Gameplay Features

- Interactive console-based gameplay
- Number-based board position selection
- Automatic win detection
- Automatic draw detection
- Prevention of invalid moves
- Prevention of selecting already occupied positions
- Continuous game-state monitoring
